# FrienDiary 모바일 앱 (React Native / Expo) — MVP

기존 웹 버전(`talkDiary`)을 React Native 앱으로 리뉴얼하는 첫 단계입니다.
이번 MVP는 **AI 대화 기능은 빼고**, 정해진 질문에 텍스트 또는 음성으로 답하면 그대로 저장되는 방식입니다. AI는 나중에 다시 붙일 예정입니다.

## 기술 스택
- **Expo (SDK 57) + TypeScript** — Android/iOS 동시 개발, `npx expo start`로 바로 실행
- **Firebase Firestore** — 기존 웹과 동일한 Firebase 프로젝트 재사용 (사용자/기록/텍스트 답변 저장)
- **expo-file-system** — 음성 답변 파일을 기기 로컬 저장소(문서 폴더)에 보관 (Firebase Storage는 유료 Blaze 플랜이 필요해 MVP에서는 사용하지 않음)
- **expo-audio** — 녹음/재생 (SDK 52+부터 `expo-av`를 대체하는 최신 API)
- **expo-speech** — 질문을 소리 내어 읽어주는 TTS
- **React Navigation** — 로그인 후 하단 탭(기록하기 / 지난 기록 / 질문 설정)

## 처음 실행하는 방법

### 1. 패키지 설치 (최초 1회)
```bash
cd mobile
npm install
```

### 2. Firebase 설정값 넣기
`.env.example`을 복사해서 `.env` 파일을 만들고, **기존 웹 버전과 같은 Firebase 프로젝트**의 값을 채워주세요.

```bash
cp .env.example .env
```

값은 Firebase 콘솔 > 프로젝트 설정 > 일반 > "내 앱" 섹션에서 확인할 수 있습니다. (웹 버전 배포용 GitHub Secrets에 이미 등록된 값과 동일한 값을 넣으면 됩니다: `FIREBASE_API_KEY` 등)

`.env`는 git에 올라가지 않으니 안심하고 실제 값을 넣으셔도 됩니다.

### 3. Firebase 콘솔에서 미리 해둬야 하는 것
이번에 새로 쓰는 리소스가 있어서, Firebase 콘솔에서 아래를 확인/설정해주세요.

- **Firestore 보안 규칙**: 새 컬렉션 `entries`를 웹 버전의 `diaries`/`users`와 같은 수준으로 읽기/쓰기 허용해야 합니다.

(Firebase Storage는 카드 등록이 필요한 Blaze 플랜에서만 켤 수 있어서, 이번 MVP에서는 사용하지 않습니다. 음성 답변은 Firestore가 아니라 **기기 로컬 저장소**에만 저장됩니다 — 아래 "알아두면 좋은 점" 참고.)

(현재 MVP는 이메일/비밀번호 기반 Firebase Auth가 아니라 기존 웹처럼 자체 닉네임+비밀번호 방식이라, 보안 규칙을 "인증 여부"로 걸 수는 없습니다. 웹 버전과 동일한 수준의 개방형 규칙을 쓰거나, 필요하면 추후 Firebase Auth 도입을 논의하면 좋을 것 같습니다.)

### 4. 실행
```bash
npx expo start
```
터미널에 뜨는 QR코드를 **Expo Go 앱**(App Store / Play Store에서 설치)으로 스캔하면 실제 기기에서 바로 확인할 수 있습니다.

## 화면 구성
- **로그인/회원가입**: 기존 웹과 동일하게 닉네임 카드 선택 → 비밀번호 로그인, 또는 신규 가입
- **기록하기 (메인)**: 고정 질문 4개(오늘 날씨, 먹은 것, 기분, 있었던 일)를 한 번에 하나씩 보여줌
  - 각 질문은 자동으로 소리내어 읽어줌 (🔊 버튼으로 다시 듣기 가능, 속도 조절 가능)
  - [텍스트] 또는 [음성] 중 골라서 답변
  - 음성은 녹음 → 미리듣기 → 필요하면 다시 녹음 가능
  - 마지막 질문에서 "저장하기"를 누르면 Firestore(`entries` 컬렉션)에 저장. 텍스트 답변은 그대로 Firestore에, 음성 답변은 **기기 로컬 저장소**(문서 폴더 `voice-answers/유저명/날짜/`)에 파일로 저장하고 그 로컬 경로만 Firestore에 기록합니다.
- **지난 기록**: 날짜별 리스트 → 탭하면 질문별 답변(텍스트는 바로 표시, 음성은 재생 버튼) 확인
- **질문 설정**: 기록할 때 물어보는 질문의 내용/순서를 자유롭게 편집. 질문 추가·삭제·▲▼로 순서 변경 후 "저장하기"를 누르면 계정(Firestore `users/{닉네임}` 문서의 `questions` 필드)에 저장되어 다음 기록부터 바로 반영됩니다. "기본 질문으로 되돌리기"로 원래 4개 질문 세트로 복원 가능.

## 알아두면 좋은 점 (추후 작업용 메모)
- **음성 파일은 기기 로컬에만 저장됩니다.** 앱을 지우거나 기기를 바꾸면 음성 답변은 사라집니다(텍스트 답변은 Firestore에 있어 안전). 여러 기기 동기화나 백업이 필요해지면 그때 Firebase Storage(Blaze 플랜)나 다른 저장소 도입을 검토하면 됩니다.
- 질문 목록은 `src/constants/questions.ts`에 하드코딩되어 있습니다. AI 대화를 다시 붙일 때는 이 파일 대신 대화형 플로우로 교체하면 됩니다.
- "주간 요약" 탭은 원래 AI가 3일치 대화를 요약해주는 기능이었는데, 이번 MVP에서는 AI가 없어서 아예 뺐습니다. AI 재도입 시 같이 복원하면 됩니다.
- 은하수(별빛) 애니메이션 같은 웹 버전의 장식 효과는 캔버스 기반이라 이번 리뉴얼에는 포함하지 않았습니다. 앱에서 다시 넣고 싶으면 `react-native-skia` 같은 라이브러리로 새로 구현해야 합니다.
